#CECS475 #Week8 
- The essence of HTML programming
- A keyword enclosed by angle brackets
	- Example: `<I>`
- There are opening and closing tags for many but not all tags
	- The affected text is between the two tags
- The opening and closing tags use the same command except the closing tag contains and additional forward slash `/`
	- Example: `<B> Warning </B>    // Output on the webpage:` **Warning**
		- Causes the word 'Warning' to appear in bold face on a web page
