#CECS475 #Week8 
- The expression below can be used to change the font of the enclosed text:
```HTML
<FONT FACE="fontname"> ... </FONT>
```

- To change the size of text use the expression below where `n` is a number between 1 & 7
```HTML
<FONT SIZE=n> ... </FONT>
```

- To change the color use the expression below
	- The color can also be defined using hexadecimal representation (Example: # ffffff)
```HTML
<FONT COLOR="red"> ... </FONT>
```

- These attributes can be combined to change the font, size, and color of the text all at once
```HTML
<FONT SIZE=4 FACE="Courier" COLOR="red"> ... </FONT>
```
