#CECS475 #Week8 
```HTML
<A HREF="page.html"> label </A>
```
- In the above link, `page.html` is the destination
	- Specifies the address of the Web page or file the user will access when he/she clicks on the click
- The label is the text that will appear underlined or highlighted on the page

Other Examples:
```HTML
<A HREF="http://www.cnn.com">CNN</A>
<A HREF="http://www.mit.edu">MIT</A>
```
