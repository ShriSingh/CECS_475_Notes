#CECS475 #Week8 
- When a Web browser displays a table, it often adds extra space. To eliminate this space use the `WIDTH=n` attribute in the `<TABLE>` and `<TD>` tags

- Keep in mind:
	- A cell cannot be smaller than its contents, and if you make a table wider than the browser window, users will not be able to see parts of it
