#CECS475 #Week8 
To create larger text areas, type:
```HTML
<TEXTAREA NAME="name" ROWS=nl COLS=n2 WRAP> Default Text </TEXTAREA>
```
- Where `n1` is the height of the next box in rows and `n2` is the width of the text box in characters

- The `WRAP` attribute causes the cursor to move automatically to next line as the user types

```HTML
<B> Comments? </B>
<BR>
<TEXTAREA NAME="Comments" ROWS=10 COLS=50 WRAP></TEXTAREA>
```
