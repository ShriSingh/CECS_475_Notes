#CECS475 #Week8 
To create a text box, type 
```HTML
<INPUT TYPE="text" NAME="name" VALUE="value" SIZE=n MAXLENGTH=n>
```
- `NAME`, `VALUE`, `SIZE`, and `MAXLENGTH` attributes are optional

[[Text Box Attributes]]

```HTML
<!-- First Name: -->
<INPUT TYPE="text" NAME="FirstName" VALUE="First Name" SIZE=20>
<BR><BR>

<!-- Last Name: -->
<INPUT TYPE="text" NAME="LastName" VALUE="Last Name" SIZE=20>
<BR><BR>
```
