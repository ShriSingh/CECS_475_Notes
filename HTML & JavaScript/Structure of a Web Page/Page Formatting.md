#CECS475 #Week8 
- To define the background color
	- Use the BGCOLOR attribute in the `<BODY>` tag
- To define the text color
	- Use the TEXT attribute in the `<BODY>` tag
- To define the size of the text
	- Type in `<BASEFRONT SIZE=n>`

Example:
```HTML
<HTML>
<HEAD>
<TITLE> Example </TITLE>
</HEAD>
<BODY BGCOLOR="black" TEXT="white">
<BASEFRONT SIZE=7>
	This is where you would include the text and images on your Web page.
</BODY>
</HTML>
```
