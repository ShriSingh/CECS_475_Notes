- Web API is the enhanced form of the web application
	- Provides services on different devices like laptop, mobile, and others
- **Web application** helps to exchange information on the internet
	- Also helps to perform a secure transaction on web sites
- Popular as the web browser is available in **default**
	- Don't need any installation of software on computers with operating systems
	- Example
		- Facebook(a social networking web application)
		- Flickr(a photo-sharing web application)
		- Wikipedia, are majorly used example of a web application
- Web application consists of two types of scripts:
	- [[Client-size Scripts]]
	- [[Server-size Scripts]]
- A web application is **Human-System interaction**
	- Either it can be single page application just to provide information for some business
	- It can be collection of web pages that are used to take some information from the user and providing the services to the user
