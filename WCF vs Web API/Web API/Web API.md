An API over the web which can be accessed using HTTP protocol
- A **concept**, *not a technology*
- Used when the application is to be used on a distributed system
- Takes requests from the different type of client devices like mobile, laptop, etc.
	- Sends them to the web-server to process it
	- Returns the desired data to the point
- Can be built using different technologies such as 
	- Java
	- .NET etc.
- Examples:
	- Twitter's REST APIs provide programmatic access to read and write data using which we can integrate twitter's capabilities into our own application
- The mostly used HTTP verbs are GET, POST, PUT, PATCH, and DELETE
	- JSON and XML file formats are used by Web APIs to transmit data over the internet
