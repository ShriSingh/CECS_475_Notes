Representation by a collection of key-value pairs
- Grouped using { }
- Rules of writing an object are:
	- Key-value pairs should be separated by a `,`(comma)
	- Each object should ***Start*** with an **Opening `{`** (Opening Curly Brace)
	- An example here is the ***Person*** Object
```JSON
{
	"FirstName" : "Virender",
	"LastName" : "Singh",
	"Age" : 34,
	"Profession" : "Engineer"
}
```
