- Stands for ***JavaScript Object Notation***
- A human and machine-readable format to represent data as ***Structured data***
- Used primarily to transfer data from one computer to another or even between different programs on the same computer
- One of the most used Data-Exchange format
- A light weight format represented as pure text
- Has the ability to parse almost all the languages to parse text
	- Is independent of the programming language
Example:
- If you want to present a ***Person***(the [[Object]]) with following details: 
	- *First Name = Virender*
	- *Last Name = Singh*
	- *Age = 34*
	- *Profession = Engineer*
- In JSON, this will turn out to be:
```JSON
"FirstName" : "Virender",
"LastName" : "Singh",
"Age" : 34,
"Profession" : "Engineer"
```
